# 100 Redações-Modelo ENEM — página de vendas

Página estática (HTML + CSS + JS inline, sem build). Publica direto pela Vercel a partir da `main`.

## Antes de anunciar
Edite só o bloco `CONFIG` no fim do `index.html`:
- `basic.checkout` / `premium.checkout`: links dos checkouts na Cakto (as UTMs da URL são repassadas ao checkout).
- `basic.price` / `premium.price`: têm de bater com a Cakto.
- `seller`: nome, CPF/CNPJ e e-mail de contato (Decreto 7.962/2013).
- `links`: Termos de Uso e Política de Privacidade (obrigatórios se houver Pixel na página).

O PDF do produto **não** fica neste repositório.
